# Результат настройки OmniRoute и DSH

> Исторический отчёт первоначальной настройки. Позднее по просьбе пользователя Codex отключён, из маршрутов и ключа DSH удалён. Текущее состояние: только Kiro FREE; см. [README](../../README.md) и [отчёт отключения](codex-disabled.md).

19 октября 2026 года. OmniRoute 3.8.51 → DSH Desktop Harness 0.2.1-rc.2.

Работает цепочка DSH → локальный OmniRoute → Codex Plus / Kiro FREE. В Desktop выбран `omniroute / DSH-Auto`. Реальная сессия получила ответ и выполнила PowerShell-инструмент с результатом `5`. Приложения не понижались в версии; исходный код не менялся.

| Маршрут | Выбор моделей |
|---|---|
| DSH-Coding | Codex gpt-6-sol → Kiro qwen3-coder-next |
| DSH-Analysis | Codex gpt-6-astra → gpt-6-sol → Kiro qwen3-coder-next |
| DSH-Fast | Codex gpt-6-luna → Kiro claude-haiku-4.5 → qwen3-coder-next |
| DSH-Auto | Автовыбор из sol, luna, Qwen Coder и Haiku с учётом доступных данных о задаче, здоровье и квотах |

Все пять выбранных моделей проверены живыми запросами. Четыре маршрута прошли генерацию кода и вызов функции. Безопасная имитация недоступного подключения подтвердила fallback; при недоступности всех тестовых кандидатов возвращается ошибка. Реальные лимиты намеренно не исчерпывались.

Подключены только официальные OAuth-пути существующей подписки ChatGPT Plus и тарифа KIRO FREE. Платных API-ключей в новых маршрутах нет. Codex использует общий лимит подписки; Kiro сообщает 50 бесплатных кредитов в месяц. Последнее наблюдение: Codex 48% текущего окна и 85% недели; Kiro 50/50 кредитов, показания могут обновляться с задержкой. Ненулевые «cost» в OmniRoute — каталожная оценка, а не подтверждённое списание. Финансовые кабинеты провайдеров отдельно не проверялись.

DeepSeek V4.1 Flash через официальный API платный; акция WorkBuddy/CodeBuddy не подтверждена как переносимая на сторонние агенты. OpenCode Free отверг запрос вне OpenCode. Qoder, Qwen Code, Kimi и Z.AI не подключены: отдельные авторизации/условия бесплатности не подтверждены. Рекламируемый Kiro `claude-sonnet-5` оказался неверным ID и удалён.

OmniRoute слушает только 127.0.0.1, стандартный пароль заменён, API требует ключ. Ключ Desktop ограничен четырьмя маршрутами и двумя подключениями, без управления сервером. Пароль и резерв ключа находятся в DPAPI-файлах вне проекта. Сбой sandbox DSH исправлен точечным правом WRITE_OWNER для владельца этого каталога; исходные ACL сохранены, sandbox включён.

Отдельный `dsh-omniroute` не установлен: штатный провайдер уже обеспечивает запросы, потоковый ответ и инструменты. Его manifest изучен; совместимость во время выполнения не заявляется без установки.

Остаются два действия пользователя: отозвать/заменить ранее раскрытые ключи Moonshot и VI; при необходимости переключить старые беседы DSH на OmniRoute, поскольку они могут помнить прежнюю модель. Для новых бесед default уже настроен.

Ограничение восстановления: исходная резервная копия DSH относилась к старому CLI-каталогу `.dsh`; активный Desktop использует `.dsh-desktop`. Его рабочая конфигурация сохранена после интеграции, поэтому точный откат прежнего Desktop default не гарантируется. Существующие ключи не удалялись.
